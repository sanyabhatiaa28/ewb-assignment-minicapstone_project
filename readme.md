
# JavaScript Curriculum: Assignments & Capstone Project

This repository contains six practical JavaScript assignments and an Interactive Product Inventory & Analytics Dashboard.

## Assignments
1. Variables, Data Types and Console Operations
2. Operators, Expressions and Input Handling
3. Conditional Logic Implementation
4. Loop Control Structures
5. Function Architecture and Scope
6. Arrays, Objects and Core Methods

## Capstone Project
**Interactive Product Inventory & Analytics Dashboard**

Features:
- Add and delete products
- Validate product names and prices
- Categorize products as Budget, Standard or Premium
- Search products by name
- Calculate total inventory value
- Display products under $200
- Generate formatted product reports
- Save inventory in browser localStorage
- Responsive frontend with a blurred pastel background

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
1. Open the project folder in VS Code.
2. Open `project/index.html` in a browser or use Live Server.
3. Add products and explore the dashboard.
4. Run the assignment files individually in a browser environment.

## Project Structure
- `assignments/` — Six JavaScript assignments
- `project/` — Dashboard HTML, CSS and JavaScript
